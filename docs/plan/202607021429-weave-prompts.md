# 新增 `weave_prompts.fish`

## Summary

新增脚本，将指定的 prompt 按参数顺序合并，同时生成内容相同的 `AGENTS.md` 和 `CLAUDE.md`。

## Implementation

- 调用格式：`./weave_prompts.fish <目标目录> <prompt名称...>`
- prompt 名称对应 `prompts/<名称>.md`，自动补充 `.md`。
- 按参数顺序合并，各文件之间保留一个空行。
- 直接覆盖目标目录中已有的 `AGENTS.md` 和 `CLAUDE.md`。
- 参数或路径无效时输出明确错误并以非零状态退出。
- 先生成完整临时文件，再替换两个目标文件。
- 在 README 中补充用途及调用示例。
